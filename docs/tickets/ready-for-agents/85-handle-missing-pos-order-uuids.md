## Customer report

Normal POS sales fail with POS Revolut installed on Odoo 18 Enterprise hosted
on Odoo.sh, using a database migrated from Odoo 15. Some historical `pos.order`
records have `uuid = False`. The reported error is
`TypeError: '<' not supported between instances of 'str' and 'bool'`.

## Agent brief

In `ReturnAllocation.acquire_many`, both `sorted(set(identities))` calls can
compare a string UUID and `False` from the same company before the loop checks
whether the UUID is present. `acquire_native_mutation` can pass UUIDs from
existing orders and `acquire_native_creation` can pass them from command
owners. `acquire_session_closure` also collects identities from native orders.

Filter empty UUIDs before sorting and reuse one sorted list of distinct valid
`(company_id, uuid)` pairs for advisory locking and payment-operation lookup.
Keep the existing lock order and retain every original order in the row-lock
and `pos_order_id` lookup paths, including orders with no UUID. Keep the
existing payment-operation and refund locking and cache invalidation.
