## Retail installation today

POS Revolut requires Odoo's `pos_restaurant` module to be installed on the database. Odoo installs it as a dependency of POS Revolut. Restaurant mode is a separate setting on each register, so a shop can install the dependency and run a normal retail register.

1. Install the matching release of POS Revolut using the [Odoo 18 installation guide](https://github.com/davaico/odoo-revolut/blob/0e515e93d4d8595ffcf71b0d9a3e45c3601be962/docs/installation.md) or the [Odoo 19 installation guide](https://github.com/davaico/odoo-revolut/blob/c2b7d40ea39d373a0ad9f9d4e11cd5bb9ddf1b7e/docs/installation.md). Leave the automatically installed Restaurant dependency in place.
2. In **Point of Sale → Configuration → Settings**, select the shop and leave **Is a Bar/Restaurant** unchecked. Close the register's session first if editing an existing configuration. Save and reopen the register. Floors, tables and split bills are unnecessary for this setup. [Odoo 18 Restaurant settings](https://www.odoo.com/documentation/18.0/applications/sales/point_of_sale/restaurant.html), [Odoo 19 Restaurant settings](https://www.odoo.com/documentation/19.0/applications/sales/point_of_sale/restaurant.html).
3. Follow the release guide to configure the server-side Merchant authority, select **Revolut** as the terminal integration for the shop's payment method, assign the method and grant till users access. Use **Check Connection** to verify the configured terminal without sending a payment. The current retail flow uses the provider's **Eat In** fulfilment value, which does not switch the Odoo register into Restaurant mode.
